# Security policy

## Supported versions

The project is under active development and has no stable release yet. Only the latest version of the `main` branch receives security fixes.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, discussions, or pull requests.**

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/JBaptisteAll/job-application-agent/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the steps to reproduce it, and its potential impact.

You can expect a first response within 7 days. Once the issue is confirmed, a fix will be prepared and you will be credited in the security advisory unless you prefer to remain anonymous.

## Personal data

This tool processes personal data such as CVs and LinkedIn archives. Any issue that could expose this data, for example a file written outside the ignored folders or data sent to an unexpected service, is treated as a security vulnerability.
